# 엣지 AI 모델 압축·배포 교육 커리큘럼 (20명)

로봇·이동체 분야 대상. "만드는 것"보다 **증류·양자화·저가 하드웨어 배포**에 집중.

## 하드웨어 편성 (추가 구매 불필요)

| 장비 | 수량 | 용도 |
|---|---|---|
| Jetson Nano (구형, JetPack 4.6.x) | 10 | 학생 실습용 (2인 1대 = 20명) |
| Jetson Orin Nano (JetPack 6.x) | 2 | 강사 시연 1 + 심화·검증 1 |
| 학생 노트북 | 20 | 이론·학습·ONNX 변환 (보드 불필요 구간) |
| MacBook (M시리즈) | 소수 예상 | MLX 병행 트랙 (02_mlx_track.md) |

- MacBook 보유율을 **사전 설문**으로 확인. 없으면 해당 학생은 ONNX Runtime(CPU) 비교로 대체.
- 구형 Nano 한계: JetPack 4.6 고정( TensorRT 8, CUDA 10.2), 720p YOLOv8n INT8 기준 10~15FPS 수준.

## 트랙 구성 (70 / 15 / 15)

| 트랙 | 파일 | 비중 | 대상 |
|---|---|---|---|
| Jetson 메인 | `01_jetson_track.md` | 70% | 전원 (보드 실습) |
| MLX 병행 | `02_mlx_track.md` | 15% | MacBook 학생 + 강사 (동시 진행) |

## 20명 운영 모델

1. **보드 의존 구간 최소화**: 학습·양자화 이론·ONNX 변환은 전원 노트북에서 동시 진행 → 보드는 배포·벤치마크 세션만 사용.
2. **2인 1대**: 10개 팀 = Nano 10대 정확히 할당.
3. **Orin 순환**: 팀별로 Orin 2대에 순서대로 접근 (최신 스택 TensorRT 10 체험, 주차별 스왑).
4. **MLX 동시 진행**: MacBook 학생은 Jetson 세션 중 이론 구간을 MLX로 병행 실습.

## 강사 준비체크 (D-7)

- [ ] 학생 MacBook(M시리즈) 보유 현황 설문
- [ ] Nano 10대: JetPack 4.6.x 통일 재플래시, microSD 상태 점검, 방열판·팬 확인
- [ ] Orin 2대: JetPack 6.x, Orin Nano Super 모드 활성화
- [ ] 공통 모델 사전 빌드: YOLOv8n/s ONNX (opset 맞추기), FP16·INT8 엔진 사전 생성
- [ ] 벤치마크 하네스 템플릿 배포 (03_cross_benchmark.md)

## 산출물 기준 (수료)

- 팀별: **하드웨어 × 모델 × 정확도/FPS/전력 매트릭스 표** 1종
- 개인별: "하나의 모델을 저가 보드까지 배포" 한 건 + 회고 1쪽
